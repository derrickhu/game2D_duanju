# 剧情视频生产管线 v0.1

> 依据：开源 AI 短剧项目和从业者经验调研（2026-10），再结合本项目的工具（Gemini NB2 出图、Vidu 出视频）。

## 2. 核心经验

1. **先建资产，再拍镜头。** 角色、场景、道具的参考图先做好、先确认，之后每个镜头都引用它们，不靠文字描述去“重新想象”长相。
2. **每个角色需要两类资产，不能互相替代：**
   - **定妆照**：正脸、中性表情、干净背景、均匀光照，用来锁脸。
   - **多视图**：全身正面、3/4 侧、正侧面、背面，同一站姿、同一比例，用来锁身形、发型和服装结构。短剧里转身、回头很常见，只有正脸参考，侧脸和背影就会漂。
   - 主要角色再加一套**表情组**（6~8 种情绪）。
3. **参考图必须“中性”。** 白底或浅灰底、平光、无表情。烘焙进参考图的逆光、雾和电影调色，会被这个角色的每个镜头继承，并和分镜里的布光打架。
   - 所以 `raw/portrait_*` 那批带场景的电影感立绘，只作为游戏内立绘和宣传图使用，**不作为视频参考**。
4. **一个造型一套多视图。** 换衣服就是一个新造型，需要单独出一套。苏晚有 5 套服装，就要 5 套多视图。
5. **连续性锁定短语。** 每个造型写一句固定的英文描述，原样粘进所有相关的出图和视频提示词，不改一个字，例如：`oversized dark charcoal hoodie, black straight-leg trousers, white canvas sneakers, vintage silver watch on left wrist`。
6. **提示词只写动作、机位和光线，不重写外貌。** 外貌交给参考图。
7. **先出静帧核对身份，再转视频。** 变脸、换衣服、换发型就重新生成，不要靠越写越长的提示词硬修。
8. **Vidu 参考图要求：** 正面或 3/4 视角，五官清晰，主体完整；一张图只放一个人。参考生视频模式最多 7 张主体图。
   - 注意：Vidu 建议避免重度磨皮导致五官特征消失。我们的画风偏精修，多视图上要保留真实的皮肤和发丝质感。
9. **时长：** 每段 4~15 秒，每镜 2~5 秒；中文台词按每秒约 4 个字估算，超了就拆镜。
10. **角色记忆点要在中景里看得见。** 短剧大部分是中景双人镜头，脸只占画面一小块。只靠五官帅撑不住，必须有：清楚的剪影（腰线、长短层次）、一块和背景对比强的颜色、一到两个固定的面部标记或配饰（泪痣、耳环、头巾）。陆屿 v1 的灰卫衣在视频里就是一坨灰，v2 改完才立住，见 `docs/drama/characters.md`。
11. **先确认再花钱。** 每批出图、出视频任务先列清单（数量、提示词、参考图、参数），确认后再执行。

## 3. 本项目管线

```
剧本（策划案 §7）
  → 资产清单：角色 × 造型、场景、道具
  → 角色资产：定妆照 + 多视图（一张设定图）→ 切成单视图
  → 场景资产：无人空景
  → 分镜：每段拆成 2~5 秒的镜头，写首帧画面、动作、台词、时长
  → 首帧：NB2 用“角色视图 + 场景空景”出首帧图
  → 视频：按镜头类型选 q4 图生 / q3-drama 参考生 / q3-turbo 图生（见 §3.0.1）
  → 质检：变脸、换装、手部、口型
  → 配音、字幕、剪辑、压缩
```

### 3.0 试拍结论（第 1 章陆屿初遇第一镜，2026-10-11）

同一个镜头试了两条路线：

| 路线 | 做法 | 结果 |
|---|---|---|
| A：参考生视频 | Vidu reference，主体为苏晚 3 张单视图、陆屿 3 张单视图、夜市空景 | 人物一致性好；但光影平、塑料感重、几乎看不到雨，推镜后陆屿挡住苏晚，构图失控 |
| B：首帧 + 图生视频（**采用**） | 三张参考拼成参考板 → Gemini 出首帧 → Vidu 图生视频，提示词只写动作和运镜 | 雨夜氛围、构图、人物一致性都达标；小问题是后半段调色偏蓝 |

- **默认走路线 B**：首帧静图便宜，可以先抽几张、挑好的再转视频，构图和光影都在静图阶段定好。
- 路线 A 留给首帧很难画、但人物必须像的镜头（比如多人大场面），或者作为路线 B 的补充。
- 成本：Gemini 首帧一张 2K；Vidu Q3 turbo 8 秒 720p 约 96 积分（约 3 元）。
- 文件：`game_assets/duanju/assets/keyframe/`（参考板和首帧）、`video/`（成片）；提示词 `docs/prompt/ch01_luyu_meet_s01_*`。

### 3.0.1 Vidu 新模型对比（2026-10）

Vidu 这段时间上了两个对我们有用的新模型：

- **viduq4-preview**：图生 / 参考生，3–16 秒，最高 4K；最多 15 张参考图 + 3 段参考音频；能克隆音色、口型同步。没有文生视频和首尾帧。
- **viduq3-drama**：短剧行业模型，只支持参考生，720p / 1080p，3–15 秒。对白、站位、镜头语言是它的强项。

同一镜头（陆屿给苏晚的推车撑伞）实拍四版：

| 版本 | 模型 · 模式 | 积分（约合人民币） | 结果 |
|---|---|---:|---|
| v1 | q3-turbo · 参考生 | 96（3.0 元） | 塑料感重，构图失控 |
| v2 | q3-turbo · 首帧图生 | 88（2.75 元） | 好 |
| v3 | q3-drama · 参考生 | 160（5.0 元） | 站位和运镜最像真短剧；表情略用力 |
| v4 | q4-preview · 首帧图生 | 152（4.75 元） | 表演最自然，构图稳 |

**结论：按镜头类型分档，不再一种模型走到底。**

| 镜头类型 | 路线 | 理由 |
|---|---|---|
| 心动 / 男主特写 / 买量素材 | 首帧 + **q4** 图生 | 表演最好，首帧锁死构图和光影 |
| 多人对峙、对白戏、打脸名场面 | **q3-drama** 参考生 | 站位、正反打、反应镜头它最会安排，省掉多张首帧 |
| 过场、空镜、走路、远景 | 首帧 + **q3-turbo** 图生 | 最便宜，质量够用 |

另外两项能力上线前要用起来：

- **主体库**：角色单视图建成主体，拿到 `server_id`，之后参考生直接引用，不用每次上传图；配音建成 `voice_id`，同一男主所有片段音色一致。
- **口型同步**（`/ent/v2/lip-sync`）：有台词的镜头先出无声视频，再配音对口型，比在生成时直接带台词更可控。

预算估算：主线 35 段 + 男主 45 段 + 番外 9 段，按每段平均 2 个镜头、混合单价约 120 积分 / 镜头，全部约 2.1 万积分（约 670 元）。错峰时段半价。

### 3.1 角色设定图规格

- 一张 16:9 设定图，纯白底，从左到右依次是：面部特写（正脸、中性表情）、全身正面、全身 3/4 侧、全身右侧面、全身背面
- 所有全身视图同一身高比例，脚踩同一水平线，同一站姿，双臂自然下垂
- 平光棚拍，中性白平衡，脚下只有淡淡的阴影
- 出图时以该角色的立绘作为脸部参考图（`--image`），保证和立绘是同一张脸
- 出完后切成 5 张单视图：`.venv/bin/python tools/split_turnaround.py <设定图> -o <views 目录>`，输出 `<角色>_face/front/34/side/back.png`
- 游戏内需要透明底的角色图时，再从正面全身视图抠图（rembg）；视频参考用白底，不用透明底

### 3.2 场景空景规格

- 和成片同比例（9:16），无人
- 写清前、中、后三层纵深和光源位置，不加氛围特效
- 首批场景：订婚宴大厅、雨夜夜市、甜品店、大学城咖啡馆、法院走廊、慈善晚宴、晚星大厦办公室、外婆老房子

### 3.3 道具

只做反复出现、剧情关键的道具：旧机械表、外婆的手写方子、旧推车、订婚戒指、沈家纹章。白底、无人无手。
