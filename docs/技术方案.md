# 技术方案 v0.1

## 1. 引擎选择：Pixi.js（不用 Unity）

| 维度 | Pixi.js 7 + TypeScript | Unity / 团结 WebGL |
|---|---|---|
| 玩法需求 | 2D、UI 为主、点数字 + 看视频，Pixi 足够 | 3D 能力用不上 |
| 视频播放 | `wx.createVideo` 原生播放器，垫在画布下，硬解、省电 | VideoPlayer 在小游戏里支持差，要绕回原生接口 |
| 包体 / 启动 | 代码包约 0.6MB，秒开 | WASM + 数据包十几 MB 起，首启慢，买量流失高 |
| 现有积累 | 剪菜、花花、火锅、消除、SRPG 都已上线，云存档、广告、CDN、分包、鸿蒙兼容全部现成 | 跑通过，但沉淀少 |
| 迭代 | 改完 1 秒出包 | 每次导出几分钟 |

**结论：Pixi。** 这类游戏的核心体验是“数字涨 → 解锁视频”，渲染压力几乎为零，决定成败的是启动速度和视频播放体验，这两点 Pixi 都占优。

## 2. 目录结构

```
src/
  data/        纯数据表：数值常量、城区门店服装、章节男主视频目录
  sim/         纯逻辑（不依赖 Pixi / 微信）：存档结构、数值公式、玩家操作、解锁推导
  managers/    GameState（玩法门面）、SaveManager、CloudSyncManager
  services/    VideoService（播视频）、StoryService（解锁判断 + 广告 + 播放）、激励广告、隐私
  scenes/      LoadingScene、HomeScene、home/ 下四个底部面板
  ui/          配色、按钮、进度条、底部弹出面板
  core/        从剪菜沿用的基础设施：Game、场景、弹层、Toast、补间、存储、平台、CDN、音频
  config/      云、CDN、广告位、事件名
tools/
  test-sim.ts    逻辑层单元测试（npm test）
  sim-pacing.ts  节奏模拟（npm run sim [每秒点击数]）
  preview.html   浏览器预览构建产物
minigame/      小游戏壳（game.js、pixi-adapter、分包占位）
platform/      各平台 game.json / project.config.json
```

分层规则：

- `sim/` 和 `data/` 只用相对路径 + `.ts` 后缀互相引用，这样 Node 可以直接跑测试和模拟，不经过打包。
- UI 只通过 `GameState` 改存档。`GameState` 负责每帧结算挂机收益、跨过门槛时发事件（章节、城区、服装解锁）、每 10 秒存盘、切后台立即存盘。
- 身价、章节、城区、服装解锁全部由存档实时推导，不单独存“已解锁”标记，避免数据不一致。

## 3. 视频播放

- 小游戏里用 `wx.createVideo({ underGameView: true })`：视频画在透明画布下方。Pixi 画布背景透明，各场景自己画一张铺满的底色；播放时隐藏当前场景和已打开的面板，画布上只留标题和“跳过”按钮。
- 第一次看要播满 3 秒才出现“跳过”，看过的随时可跳。
- 视频走 CDN 直链 `videos/<id>.mp4`，不打进包。CDN 域名要加到小程序后台的 downloadFile 合法域名。
- 缺片时提示“剧情视频制作中”，解锁逻辑照常推进，所以可以边做视频边测玩法。
- 浏览器预览用 `<video>` 元素垫在画布下面，逻辑一致。

## 4. 广告

激励视频广告位在 `src/config/AdsConfig.ts`，和策划案 §9 一一对应：急单、直播带货、离线翻倍、加急装修、男主番外、隐藏结局。广告位 id 留空时：开发者工具里直接发奖，真机提示“广告暂时播不了”。

## 5. 存档与云同步

- 本地存档键见 `CloudConfig.SAVE_KEY`，结构见 `src/sim/save.ts`，读档时 `normalizeSave` 兜底坏数据。
- 云同步沿用剪菜的 CloudBase HTTP 方案，后端云函数部署前 `BACKEND_ENABLED = false`，只用本地存档。

## 6. 开发命令

| 命令 | 作用 |
|---|---|
| `npm run build:wechat` | 打包到 `build/wechat/`，微信开发者工具打开这个目录 |
| `npm run dev` | 监听改动自动打包 |
| `npm run typecheck` | 类型检查 |
| `npm test` | 逻辑层测试 |
| `npm run sim` / `npm run sim -- 2` | 节奏模拟，默认每秒点 4 次 |

GM 按钮（身价 ×10）只在微信开发者工具里出现。
