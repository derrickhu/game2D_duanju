## 一、这一版改了什么

**1. 每个男主都有两面：“她看见的”和“她看不见的”。** 对她，他们给的都是真心，而且是最好的那一面；对别人，他们冷漠、狠、双标，或者在背后替她做了很多事却不说。玩家越看暗面，越觉得他对女主的温柔珍贵。

**2. 男主线拆成两条。**
- **心动线**（5 段）：和女主的相处，甜、暧昧、告白、约会。台词里埋一点暗面的伏笔。
- **暗面线**（3 段）：男主自己，或男主和别人。女主不在场，或者在场也不知道真相。其中 1 段放进看广告解锁的“花絮”。
- **结局揭底**：每个男主的专属结局，都是女主第一次看见他的暗面。前面攒的情绪在这里一次兑现。

**3. 主线只讲女主的成长和打脸。** 男主可以帮忙，但每一次关键的打脸都由苏晚自己完成。男主在背后做的事放进他们自己的暗面线，主线里最多留一个镜头的伏笔。

**4. 加了女配情敌。**
- **苏婉柔 → 陆屿**：主线大反派的动机多了一层。她在乡下长大，陆屿每年夏天去看奶奶，她暗恋了他十五年；可陆屿每次来，只问奶奶“苏家那个女孩过得好不好”。她恨苏晚，不只是因为身份。
- **唐沁 → 霍霆琛**：霍家安排的联姻对象，名媛。被他当着全家的面拒绝。
- **姜蔓 → 周以宁**：当红小花，硬炒 CP，被他在镜头前当场拆台。
- 另有一场戏的路人情敌：江叙白的系花、秦朔的赛车女主播、顾野的富婆会员。

**5. 陆屿从“默默守护”改成“早就爱上、有目的地接近”。** 第 7 章女主发现一切都是他算好的，两人第一次决裂；第 8 章结局再和好。主线多了一条感情上的起伏。

序章和第 1 章**不改**，已经拍好的视频可以直接用。第 2~8 章只改下面这些段落，其余照 v2。

### 第 7 章 · 恭迎大小姐（重写）

1. **外婆的铁盒（12 秒）** 外婆老房子的阁楼，苏晚打开一个铁盒：盛家全家福、一枚纹章、一封信，信封上是陆屿的字迹：“奶奶，我找到她了。我会接近她，带她回家。”落款是七年前。

3. **恭迎大小姐（14 秒）** 盛家老宅，苏婉柔拿着伪造的 DNA 报告对律师哭：“我才是盛家的外孙女！”大门打开，苏晚自己走进来，身后是许知衡：“真报告在这里。”管家艾伦和保镖厉锋带两排人鞠躬：“恭迎大小姐回家。”苏晚坐上主位，第一句话：“报警。”
4. **最后一行（14 秒）** 深夜，苏晚独自坐在老宅书房，展开外婆留给她的信，最后一行写着：“当年那场车祸不是意外。凶手，是你叫了二十二年的爸爸。”窗外，陆屿撑着伞站在雨里，没有走。

**钩子**：她会原谅陆屿吗？终章清算。

### 陆屿 · 隐藏继承人
**暗面：盛家的“笑面阎王”**

> 外婆的亲孙子，从小被盛老爷子收养。十五年前，外婆带他去苏家后门送东西。他饿着肚子站在门外，一个扎辫子的小女孩跑出来，把手里唯一一块星星酥塞给他：“给你，我外婆做的，最好吃。”那是他第一次见她。
> 七年前老爷子临终，把盛氏交给他代管，让他找回她。他在盛家董事会笑着把叔伯一个个送进监狱，外人叫他“笑面阎王”。夜市的烧烤摊，就摆在她推车隔壁，是他算好的位置。
> **在她面前**：话少，笨拙，会脸红，会做饭，从不提自己。**在家族里**：笑着杀人不见血。

**心动线**
> 真人版现行剧本和制作状态见 `hero_live/陆屿.md`，以那里为准。

1. **初遇** 雨夜，他把伞塞进她手里，自己淋着雨走回烧烤摊。她喊：“你的伞！”他回头一笑：“推车比我金贵。”
2. **心动** 她烫伤了手，他一言不发地拿冰袋按上去，包扎得又快又熟练。她：“你一个烤串的，怎么这么会包扎？”他：“烤串的，也会受伤。”
3. **暧昧** 片头黑屏：晚上，蛋糕烤失败了，两个人分着吃这块失败的蛋糕。窗边，他看着她嘴角的奶油：“难吃。但我想天天吃。”
4. **告白** 天台，她问：“你到底是谁？”他看着她：“现在还不能说。但我是你的人，这句不会变。”
5. **专属约会**（第 8 章后）外婆老房子的屋顶，满城灯火。他把纹章表扣到她手腕上：“七年前我就该来找你。是我胆小，拖到现在。”

**暗面线**
- **A · 笑面阎王** 盛家中式宅院，他穿月白盘扣衫、墨黑长外套，冷着脸吩咐下面的人：“告诉周家，明早九点前签字。过了九点，就不用签了。”手机响了，来电显示“晚晚”，他立刻换上乖巧的笑和撒娇的语气：“晚晚～我在店里搬货呢，好累哦。”（真人版重做中）
- **B · 十五年** 盛家后门，苏婉柔拦住他，眼泪掉下来：“我等了你十五年。你每年夏天来乡下，只问奶奶她过得好不好……那我呢？”他：“我从没给过你期待。”她：“她到底哪里好？”他：“她会把唯一一块星星酥，给一个不认识的小孩。你会吗？”转身就走。
- **C · 花絮（广告）· 一百盒** 晚星开业那天，一口气买走一百盒星星酥的匿名客人是艾伦。陆屿的冰箱里码着整整一百盒，他一盒一盒地吃。艾伦：“少爷，过期了。”他：“过期了，也是她做的。”

**专属结局 · 糖纸**
苏晚第一次走进他的书房。墙上只挂着一个相框，里面是一张皱巴巴的旧糖纸，十五年前包星星酥的那张。他穿求婚夜的象牙白银线刺绣三件套，她穿终章星河藏青立领礼服。他：“从你给我那块星星酥开始，我就是你的人了。”她：“这次，我点头。”两人拥抱。

### 江叙白 · 温柔学弟
**暗面：白切黑，黑客“K”**

> 计算机系天才，全网有名的白帽黑客“K”。对所有女生礼貌又疏远，对情敌是绿茶，对欺负她的人睚眦必报。他把所有撒娇、脸红和耐心都给了“姐姐”。

**心动线**
1. **初遇** 拉花拉成一只歪歪扭扭的猫，他红着脸推过来：“送你的……姐姐。”
2. **心动** 大雨天，他骑单车绕了半座城，浑身湿透地把她落下的方子送回来：“姐姐的东西，我不会弄丢。”
3. **暧昧** 手把手教她拉花，耳朵红透。顾野来找她，他抬头一笑：“姐姐，他会做咖啡吗？我会。”
4. **告白** 打烊后，桌上一杯拉花写着“我喜欢你”。他低着头：“我不想只做你的学弟了。”
5. **专属约会** 毕业典礼，他把学士帽戴到她头上：“姐姐，我毕业了。以后换我保护你。”

**暗面线**
- **A · 双标** 图书馆，系花红着脸递来情书：“江同学，我喜欢你很久了。”他头也不抬：“同学，你挡到我的光了。”系花走后手机一震，屏幕上是“姐姐：店里的咖啡机坏了”。他抓起外套就跑，笑得露出虎牙：“马上到！”
- **B · K**（接第 3 章）深夜宿舍，三块屏幕亮着。苏婉柔直播翻车后，买了三千个水军账号骂晚星。他敲下回车，三千个账号同时发出同一句：“我是收钱的水军，雇主是苏婉柔。”他喝了口冷掉的咖啡：“欺负我姐姐，要付利息。”
- **C · 花絮（广告）· 醉话** 他喝醉了趴在吧台上，拽着她的衣角不撒手：“姐姐别走……那些骂你的人，我一个都没放过……”她一愣：“什么？”他已经睡着了。

**专属结局 · 最后一行代码**
晚星新系统上线那天，开机画面跳出一行代码注释：“// 守护对象：苏晚。期限：永久。署名：K。”她回头，他单膝跪下，戒指放在一杯拉花成星星的咖啡旁：“姐姐，这辈子写的第一行和最后一行代码，都给你。”

### 顾野 · 阳光教练
**暗面：地下拳台的“野狼”**

> 十七岁为了给妹妹凑手术费打黑拳，眉骨那道疤就是那时留下的。妹妹没救回来，他从此金盆洗手开了拳馆，再也没为谁出过手，直到遇见她。
> **在她面前**：爱笑，有酒窝，傻乎乎地喊“老板”。**在别人面前**：一句话不多说，狠起来不要命。

**心动线**
1. **初遇** 她来考察，他以为是新会员，热情地把她拉上跑步机：“体能不行啊，新来的？”店长跑过来：“这是老板！”他当场僵住。
2. **心动** 她加班到深夜，他提着便当出现：“老板也得吃饭。不吃完不许走。”
3. **暧昧** 教她防身术，过肩摔时稳稳接住她。她伸手碰了碰他眉骨的疤：“怎么弄的？”他笑：“小时候爬树摔的。”
4. **告白** 海边晨跑，他突然停下，对着大海喊：“苏晚，我喜欢你！”转头：“没听见我再喊一遍。”
5. **专属约会** 山顶露营，日出时他把她抱起来转了一圈：“以后每个日出，我都想第一个看见你。”

**暗面线**
- **A · 野狼** 地下停车场，苏婉柔雇来的七个人堵在苏晚车边。顾野一个人站在出口，慢慢缠好红色绑手带：“十年没动手了。你们运气不好。”画面切黑，只剩闷响。第二天他手上缠着纱布，对她笑：“搬器材砸的。”
- **B · 双标** 富婆会员把房卡塞进他口袋：“顾教练，私教课，价钱随你开。”他把房卡扔进垃圾桶：“我只教一个人防身，别的不教。”一转身看见苏晚，立刻把手藏到背后，笑出酒窝。
- **C · 花絮（广告）· 念念** 墓园，他把一盒星星酥放在一块小小的墓碑前：“念念，哥遇到一个人，笑起来跟你一样。这次，哥一定护得住。”

**专属结局 · 认输**
拳台上撒满星星灯。他戴着拳套单膝跪下，拳套里夹着戒指：“这次我认输，输给你一辈子。”她低头亲了一下他眉骨的疤：“爬树摔的？”他愣住，眼眶一下子红了。

### 沈砚 · 冷面律师
**暗面：父亲没打赢的那场官司**

> 父亲沈正清是二十二年前盛家车祸案的检察官，被苏父买通的人陷害，辞职后郁郁而终。父亲的旧卷宗里有一张照片：一页手写方子，角落画着一颗小星星。
> 所以苏晚把方子推到他面前的那一刻，他就知道她是谁。
> **对别人**：毒舌、冷血，法庭上从不留情面，被同行叫“法庭刽子手”。**对她**：唯一的破例。

**心动线**
1. **初遇** 他头也不抬：“胜算三成。”她：“那就三成。”他终于抬眼看了她一下。
2. **心动** 下庭后她问律师费多少，他扶了扶眼镜：“先欠着。”
3. **暧昧** 深夜整理案卷，她趴在桌上睡着了。他摘下眼镜，把大衣披在她身上，低声说：“笨蛋。”
4. **告白** 他递给她一份《终身法律顾问合同》。她翻到最后一页，期限写着：一辈子。“我这辈子只打过一场免费的官司。”
5. **专属约会** 他母校的图书馆，一张旧书桌上刻着一行小字：“将来要为不认命的人辩护。”他说：“十年前写的。今天找到了那个人。”

**暗面线**
- **A · 刽子手** 茶室里，苏家律师推过来一张支票：“沈律师，开个价，撤诉。”他看都不看，把支票折成纸飞机扔回去：“我的价，你们苏家付不起。”
- **B · 旧卷宗** 深夜律所，他打开一只落满灰的纸箱，标签写着“盛家车祸案·沈正清”。照片里是一页方子，角落一颗小星星。他摘下眼镜，声音哑了：“爸，我找到她了。这次，我们会赢。”
- **C · 花絮（广告）· 告白陈述书** 他在办公室一遍遍改一份《告白陈述书》，删了又写，最后只剩一句：“我喜欢你。证据确凿。”

**专属结局 · 唯一的合同**
律所落地窗前，他把父亲的旧卷宗合上，换成一份《婚姻登记申请》，戒指放在上面：“我父亲没打赢的官司，我替他赢了。剩下的一辈子，我只替你辩护。苏小姐，请签字。”

### 秦朔 · 痞帅赛车手
**暗面：退役车神“零号”**

> 三年前一场事故，搭档阿哲死在他副驾上。从那以后他不碰赛道、不笑，对谁都冷，窝在改装车行修车。是她让他重新回到赛道。

**心动线**
1. **初遇** 她的车在江边抛锚，他骑机车停下，叼着棒棒糖：“大小姐的车也会坏？”修车的手却很快。
2. **心动** 第一次带她坐机车，回头把头盔扣到她头上：“抱紧点，摔了我可赔不起。”
3. **暧昧** 复出赛前夜，他把自己的幸运手环套到她手腕上：“明天你坐第一排。别看别人。”
4. **告白** 拿下冠军，他当着全场镜头举起奖杯：“这个冠军是她的。”大屏幕切到看台上的苏晚。
5. **专属约会** 深夜的跨江大桥，只有他们两个人。他停下车：“这座城的灯，今晚都是为你亮的。”

**暗面线**
- **A · 三年没笑** 欧阳澈小声对罗川说：“老大三年没笑过，今天对着手机笑了五次。”画面里，秦朔看着苏晚发来的车坏了的照片，嘴角压不住。赛车女主播靠过来：“复出赛带我坐副驾？”他眼皮都没抬：“我的副驾只坐一个人。”
- **B · 刹车** 深夜车库，他蹲在苏晚的车底下，手电照着被剪了一半的刹车线。他沉默地换上新的，又在车里装了行车记录仪。第二天她来提车：“没什么毛病吧？”他叼着棒棒糖：“小毛病，修好了。”
- **C · 花絮（广告）· 弯道** 深夜空荡的赛道，他把一束花放在三年前出事的那个弯道：“阿哲，我要回赛道了。这次副驾上的人，我拿命护着。”

**专属结局 · 终点**
赛道终点，他摘下头盔，冠军奖杯里放着一枚戒指。她手里拿着一段行车记录仪的视频，眼睛红了：“刹车那次，你为什么不说？”他笑：“说了你就不敢坐我的车了。跑了这么多年，终点一直是你。”

### 许知衡 · 温柔医生
**暗面：没有温度的手术刀**

> 天才外科医生。对谁都温和有礼，可同事都说，他的心比手术刀还冷，从不给权贵插队，也从不对谁破例。他和她一样，是熊猫血。

**心动线**
1. **初遇** 急诊室，他一边处理伤口一边说：“疼就抓着我。”她攥住了他的白大褂袖口。
2. **心动** 她出院那天，翻开病历本，最后一页写着一行小字：“记得按时吃饭。——许”
3. **暧昧** 夜班间隙，两人在值班室吃泡面。他把自己碗里的溏心蛋夹给她：“病人优先。”
4. **告白** 医院天台，他摘下口罩：“我见过很多病人。只有你，让我想陪到最后。”
5. **专属约会** 郊外的星空观测站，他调好望远镜让她看：“那颗最亮的，我申请用你的名字命名了。”

**暗面线**
- **A · 400 毫升**（接第 5 章）血库告急的那晚，许知衡挽起袖子坐进采血室。护士程朗急了：“许医生，你刚做完两台手术！”他闭上眼：“抽。别告诉她是我。”半小时后，他脸色发白地走到她床边，笑着说：“血库调到了。”
- **B · 温柔刀** 苏婉柔装病住进 VIP 病房，点名要他看诊。他戴好手套，微笑着拿起针：“苏小姐，这一针会很疼。”她吓得发抖。他俯身，声音很轻：“推她下楼的时候，你想过她疼吗？”
- **C · 花絮（广告）· 练习** 值班室里，他对着手机里她的照片小声练习告白，被程朗撞个正着。程朗：“许医生，原来你会笑啊。”

**专属结局 · 心跳**
诊所的樱花树下，她终于从程朗嘴里知道了那 400 毫升的事。她红着眼看他，他把听诊器按在自己胸口，另一头递给她：“听见了吗？它说，要娶你。”

### 周以宁 · 落难顶流
**暗面：宁折不弯**

> 三年前他还是被欺负的练习生，在一场慈善活动里打杂，被人当众泼了一身饮料。是苏家大小姐替他解了围，递给他一张名片，背面写着：“想唱就别停。”她早忘了，他一直留着。
> 他所谓的“塌房”，是因为拒绝了资本大佬的饭局，被雪藏、被造谣。
> **对资本和炒作**：硬到底，不低头。**对她**：把全部的光都给她。

**心动线**
1. **初遇** 雨天的天桥上，他戴着口罩被狗仔追，拉开她的车门钻进来：“开车。求你。”认出她的那一刻，他在口罩下愣住了。
2. **心动** 全网传他塌房，她开发布会：“他是我签的人，我信他。”后台，他红着眼：“你是第一个信我的人。”
3. **暧昧** 练舞室，他教她跳舞，镜子里两个人越靠越近，他忽然停下：“老板，你心跳好快。”
4. **告白** 演唱会安可，他唱了一首没发行过的歌，叫《晚星》。唱完对着镜头：“我恋爱了。”热搜当场爆了。
5. **专属约会** 凌晨空荡的体育场，只亮着一束光。他坐在舞台边：“今天这场，观众只有你一个。”

**暗面线**
- **A · 拆台** 综艺录制，姜蔓当着镜头挽住他的胳膊：“我们以宁私下可照顾我了。”他抽回手，看着镜头：“不熟。别碰我。”全场冷场。经纪人崩溃，他戴上耳机，手机屏保是一张泛黄的旧名片。
- **B · 饭局** 三年前的包厢，资本大佬把酒杯推过来：“喝了这杯，明年给你 C 位。”他把酒倒在地上：“我唱歌，不陪酒。”第二天，所有通告被撤。画面回到现在：后台，他把那张名片攥在掌心。
- **C · 花絮（广告）· 楼下** 狗仔拍到他凌晨蹲在她家楼下，经纪人崩溃：“祖宗，你能不能低调点！”他：“不能。”

**专属结局 · 想唱就别停**
演唱会最后一首歌，大屏幕上出现一张泛黄的名片，背面写着“想唱就别停”。全场灯光熄灭，只剩一束光打在台下的她身上。他单膝跪在舞台边：“三年前你让我别停。我没停，就是为了今天站到你面前。”

### 霍霆琛 · 宿敌霸总
**暗面：冷血的“收购机器”**

> 霍家私生子，一路狠到继承人的位置。商场上从不手软，家族给他安排了联姻对象唐沁。
> 他真的在商战里输给了她。从那以后，他在背后替她挡下了更大的刀，却不准任何人告诉她，因为“她要赢，就得赢得干干净净”。
> **对外**：冷血、强势。**对她**：笨拙，还说土味情话。

**心动线**
1. **初遇** 酒会上，他晃着酒杯：“苏小姐的甜品店，我一个月就能挤垮。”她碰了一下他的杯子：“那霍总，我们赌一个月。”
2. **心动** 商战落败，他看着财报，第一次笑了：“你是第一个赢我的人。”
3. **暧昧** 签合作协议，他把笔递得很慢，指尖碰了一下她的手：“苏总，晚饭有空吗？这次不谈生意。”
4. **告白** 顶楼停机坪，风很大，他把西装外套披到她身上：“我输给你一次，想再输一辈子。”
5. **专属约会** 私人飞机降落在北极圈，满天极光。他说：“全世界的光，今晚都归你。”

**暗面线**
- **A · 不是你** 霍家家宴，霍老爷子宣布他和唐家千金唐沁订婚，唐沁含羞起身。霍霆琛放下刀叉：“霍家的女主人，我已经选好了。不是唐小姐。”老爷子摔了杯子：“你敢！”他扣好西装起身：“我连霍家都敢收，你说我敢不敢？”
- **B · 干净地赢** 海外资本准备做空晚星。助理：“霍总，我们只要袖手旁观，晚星必死，霍氏就能吃下它。”他把文件撕了：“替我截下来。她要赢，就得赢得干干净净。别让她知道。”
- **C · 花絮（广告）· 不土** 助理汇报：“苏总说您的告白台词太土。”他沉默三秒，打开搜索栏，输入：“怎么追女孩子 不土”。

**专属结局 · 不是收购**
苏晚把一份海外资本的调查报告放到他桌上：“那次做空，是你截下来的？”他别开眼：“顺手。”霍氏大厦外墙亮起一行字：“苏晚，嫁给我。”他在顶楼单膝跪下：“这次不是收购，是求婚。”
