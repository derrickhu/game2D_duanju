# 剧情与设定 · 总索引

> 先看这里。每一类设定只有一份「现行版本」，改的时候改它，再按下面的同步表把下游一起改掉。旧版本文件只留档，不再改。

## 现行版本

| 内容 | 现行文件 | 说明 |
|---|---|---|
| 剧情（主线 + 男主线 + 情敌） | `剧情大纲_v3.md` | v2 只留档。男主线的台词以各男主真人登记表为准，大纲里同步改 |
| 男主真人专属剧情 | `hero_live/<男主>.md` | 造型 ↔ 剧集对应、现行剧本、首帧、提示词、成片、入游戏状态、变更记录。目前有：`陆屿.md` |
| 角色造型、锁定短语、参考图 | `characters.md` | 厚涂 / v10 设定图；真人线造型见 `hero_live/` |
| 音色 | `voices.json` | 一个角色一个音色，定了不换 |
| 主线分镜 | `chNN_<章名>/分镜.md` | 每章首帧、时长、提示词 |
| 主线配音混音 | `dub/<章>.json` | `tools/dub_mix.py` 的输入 |
| 视频生产方法 | `../视频管线.md` | 真人男主线做法在 §3.0.2 |
| 游戏内数据 | `src/data/story.ts` | 视频 id、标题、解锁条件；成片在 `minigame/videos/<id>.mp4`，走 CDN |
| 游戏玩法 | `../策划案.md` | |

资产（图、视频母版）都在仓库外 `game_assets/duanju/assets/`；真人线在 `live_v1/`。

## 改动要同步的地方

| 改了什么 | 还要改 |
|---|---|
| 男主某集剧本 / 台词 | `hero_live/<男主>.md` 剧集表 + 变更记录；`剧情大纲_v3.md` 对应条目；对应提示词文件 |
| 男主新增 / 替换造型 | `hero_live/<男主>.md` 造型表；新设定图放 `live_v1/` 并裁参考图 |
| 重出了某集视频 | `hero_live/<男主>.md` 成片列和状态；旧片改名 `_try<N>` 留档 |
| 视频入游戏 | 登记表状态改「已入游戏」并写 CDN manifest 版本；`story.ts` 标题如有变化一起改 |
| 新角色开口 | 先在 `voices.json` 定音色 |
| 摸索出新的生成经验 / 踩坑 | `../视频管线.md` 对应小节 |
