## 一、这一版改了什么

**1. 每章都按“压 → 打脸 → 钩子”三拍写。** 前两段受辱，第三段反转打脸，第四段留一个悬念把玩家钩到下一章。旧版大部分章节第 4 段是“收尾”，看完没有继续的理由。

**2. 所有坏事背后都是苏婉柔。** 旧版王姐、周房东、抄袭、推楼梯各是各的。新版王姐是她花钱雇的，二房东是她买通的，抄袭用的是她当年从外婆方子上撕走的那几页。玩家会一路攒着火，第 8 章一次清算。

**3. 身世线提前埋伏笔。** 序章就让陆屿的纹章表露一个镜头，第 2 章暗示楼是他买的，第 4 章苏婉柔撂下一句“你连自己是谁都不知道”，第 5 章医生发现血型异常，第 7 章再揭开。

**4. 加入短剧观众熟悉的套路和梗**，但让女主用自嘲的方式接住，避免尬：
- 真假千金、当众退婚、栽赃偷项链、白莲直播翻车
- “离开傅家你什么都不是”、黑卡砸场、“我出十倍”、二房东反转
- 恶人先告状、泼红酒、推下楼梯、熊猫血
- 跪求注资、雨中求复合、“天凉了，苏氏该换主人了”
- “女人，你成功引起了我的注意”（女主当场吐槽台词过时）
- 黑车车队、“恭迎大小姐回家”、DNA 报告、假千金冒充真千金
- 发布会公开处刑、追妻火葬场双结局

**5. 设定调整（需要你确认）：**
- **首富家族“沈家”改成“盛家”。** 男主沈砚也姓沈，身世揭开时观众会以为他俩是亲戚。“盛”在仓库里没有用过。
- **陆屿不再是“沈家远房继承人”，改为外婆的亲孙子、盛老爷子的养孙。** 旧设定里他和女主是远房亲戚，做主线男主不合适。新设定：外婆是盛家的老管家，陆屿从小被盛老爷子收养，老爷子去世后他替女主代管盛氏七年，一直在找她。“隐藏继承人”的称号仍然成立。
- **调包的真相写得更狗血：** 二十二年前，苏父是盛家的合伙人，他设计了一场车祸，害死了盛家独女夫妇，吞了盛家的食品配方，这才有了苏氏食品。外婆察觉到危险，在医院把盛家的女婴和同一晚出生的苏家女婴调了包，让盛家唯一的血脉藏在仇人家里长大（最危险的地方最安全），自己以保姆身份跟进苏家守着她。真正的苏家女儿苏婉柔被送到外婆乡下的妹妹家，吃了二十年苦，所以回来以后格外恨苏晚和外婆。

## 三、主线

### 序章 · 退婚宴（身价 0，强制播放）

> 目标：40 秒内把情绪压到最低，结尾一句旁白钩住。

1. **订婚台上（6 秒）** 花拱门下，苏晚穿樱花粉纱裙举杯，傅景辞扶着她的腰。宾客鼓掌。下方小字“云城 · 苏家订婚宴”。
2. **真千金进门（10 秒）** 大门推开，苏母牵着一身白裙的苏婉柔走进来。苏父：“她才是我们的亲生女儿。”全场哗然。苏婉柔怯生生地看了苏晚一眼，嘴角飞快地勾了一下。
3. **栽赃 + 退婚（12 秒）** 苏婉柔捂着脖子惊叫：“妈，我的项链不见了！”保镖从苏晚手包里翻出钻石项链。苏母一巴掌扇过去。傅景辞摘下苏晚的订婚戒指，戴到苏婉柔手上：“离开苏家，你什么都不是。”
4. **雨夜夜市（12 秒）** 大雨，苏晚穿着湿透的礼服，推着外婆的旧推车停在夜市入口，怀里死死护着一本被撕掉几页的手写方子。街角停着一辆黑色轿车，车窗半降，一只戴着古董表的手一闪而过（陆屿的纹章表，伏笔）。旁白：“那一晚，所有人都在笑我。后来，他们排队等我回头。”

**钩子**：谁撕了方子？车里的人是谁？

### 第 1 章 · 摆摊第一天（1 万）

1. **第一批客人（10 秒）** 夜市，苏晚手忙脚乱地做星星酥，第一个客人咬了一口愣住，转身对后面的人喊：“快来！”长队排了起来。
2. **地痞掀摊（10 秒）** 王姐带人一脚踹翻推车：“这片地盘交保护费了吗？”星星酥滚了一地。
3. **烧烤摊少年（10 秒）** 隔壁烧烤摊的陆屿放下烤串，走过来扣住王姐的手腕，一句话不说。王姐疼得脸都白了，带人跑了。他蹲下帮她捡起推车。
4. **幕后黑手（10 秒）** 巷子里，王姐打电话：“苏小姐，那丫头有人护着……”镜头切到电话另一头，苏婉柔在苏家豪宅里修指甲：“那就再找人。”收摊后，苏晚数着皱巴巴的钞票笑了。旁白：“第一天，我赚了一万。”

**钩子**：苏婉柔不会罢休。

### 第 2 章 · 全款拿下（10 万）

1. **涨租十倍（10 秒）** 苏晚看中临街小铺面，周房东上下打量她：“假千金也想开店？房租翻十倍，爱租不租。”
2. **二房东反转（12 秒）** 苏晚把手机推过去，屏幕上是刚签的合同：“你只是二房东。业主刚把整层直接租给我了，下个月起，你的合同不续。”房东脸色发青。
3. **开业排长队（10 秒）** 晚星甜品店开业，门口排到街尾。周房东在人群外偷偷打电话：“苏小姐，没拦住……”
4. **他到底是谁（12 秒）** 打烊后，陆屿系上围裙站到她身边：“缺人吗？”她笑着点头。镜头拉远，街对面，一个西装男人对陆屿微微鞠躬，递上一份文件，封面写着“产权证”（这栋楼是他买的，苏晚不知道）。

**钩子**：那个业主，是陆屿？

### 第 3 章 · 黑卡砸场（100 万）

1. **白莲吃出头发（12 秒）** 苏婉柔挽着傅景辞走进店里，开着手机直播。她咬一口甜品，夸张地吐出来：“天哪，里面有头发！家人们，这就是假千金开的黑店！”直播间弹幕刷屏骂人。
2. **黑卡砸场（10 秒）** 傅景辞甩出一张黑卡：“这家店我买了。晚晚，回来求我，我还能给你个位置。”
3. **监控打脸（12 秒）** 苏晚不慌不忙，让店员把监控投到墙上：画面里，苏婉柔从自己口袋里捏出一根头发放进碗里。直播间弹幕瞬间反转：“白莲翻车了！”排队的顾客齐声：“道歉！”
4. **新的阴谋（12 秒）** 苏晚把黑卡推回去：“本店不卖。插队，按十倍收费。慢走不送。”苏婉柔狼狈离开。当晚，全城最大的广告牌亮起：苏氏食品新品“星星酥”，包装上印着和外婆方子一模一样的花纹。苏晚站在牌子底下，攥紧了那本缺页的方子。

**钩子**：被撕走的那几页，原来在苏家手里。

### 第 4 章 · 恶人先告状（1000 万）

1. **反被起诉（10 秒）** 苏晚刚准备维权，先收到了法院传票：苏氏食品起诉晚星抄袭。热搜第一：“假千金偷苏家配方”。店门口被人泼了红漆。
2. **胜算三成（10 秒）** 律所，沈砚头也不抬：“对方证据很全，胜算三成。”苏晚把缺页的方子放到他面前：“那就三成。”
3. **撕页对上了（14 秒）** 法庭上，沈砚请苏家交出“原始配方”，把它和苏晚的方子对在一起：撕口严丝合缝。他再打开紫光灯，每一页角落都浮出一颗外婆画的小星星。苏家律师哑口无言。
4. **你连自己是谁都不知道（12 秒）** 判决：苏氏食品侵权，公开道歉，全线下架。法院台阶上，苏婉柔擦肩而过，压低声音：“你以为你赢了？你连自己是谁都不知道。”苏晚猛地回头。

**钩子**：苏婉柔知道了什么？

### 第 5 章 · 千万晚宴（1 亿）

1. **门口被拦（10 秒）** 苏父苏母被拦在慈善晚宴门口：“抱歉，今晚只接待捐赠一千万以上的嘉宾。”身后，一身香槟金礼服的苏晚从他们身边走过，侍者鞠躬：“苏总，这边请。”
2. **泼红酒（12 秒）** 宴会厅里，苏婉柔“不小心”把一整杯红酒泼在苏晚裙子上：“姐姐，对不起呀。”全场看笑话。主持人：“今晚最大的捐赠人，晚星创始人，苏晚女士。”苏晚提着染红的裙摆，从容走上台，聚光灯打在她身上。
3. **推下楼梯（10 秒）** 后台楼梯间，苏婉柔拦住她，眼神阴冷：“盛家的东西，凭什么是你的？”她伸手一推，苏晚从楼梯上摔了下去。
4. **熊猫血（12 秒）** 急诊室，许知衡按住她的伤口：“疼就抓着我。”护士跑进来：“许医生，她是熊猫血，血库告急！”许知衡看着化验单，皱起眉：“这个血型……我二十年来只在一份旧病历上见过，病人姓盛。”

**钩子**：盛家是谁？

### 第 6 章 · 跪求注资（10 亿）

1. **苏氏崩盘（10 秒）** 下架加热搜，苏氏食品股价跌停。董事会上，苏父摔了文件：“谁能救苏氏？”秘书小声说：“现在只有晚星有这个钱。”
2. **前台等三小时（10 秒）** 苏父苏母在晚星大厦前台坐了三个小时，前台第七次续茶：“苏总还在开会。”
3. **天凉了（14 秒）** 会议室，苏父想跪，苏晚伸手拦住：“别跪，我受不起，也不想受。”她把收购协议推过去：“签了它，苏家还能留个名字。”转头对秘书说：“天凉了，苏氏该换个主人了。”
4. **雨中求复合（14 秒）** 门外大雨，傅景辞浑身湿透地站在雨里，手里攥着一段录音：“晚晚，推你下楼的是婉柔，项链也是她自己放的……我全都知道了。我错了，你回头看我一眼。”**进入双结局选择**（见“傅景辞”）。选择后接一个镜头：大屏幕插播财经新闻，霍霆琛面对镜头：“一个月，晚星改姓霍。”

**钩子**：真正的对手来了。

### 第 7 章 · 恭迎大小姐（100 亿）

1. **土味霸总（12 秒）** 霍氏谈判桌上，霍霆琛靠在椅背上：“女人，你成功引起了我的注意。”苏晚合上文件：“霍总，这句台词十年前就过时了。”霍霆琛愣住，助理憋笑。
2. **外婆的信（14 秒）** 外婆老房子里，苏晚在阁楼找到一个铁盒：一张盛家全家福、一枚纹章、一封信。纹章和陆屿手表上的一模一样。她转身，陆屿就站在门口：“外婆是我亲奶奶。她守了你二十二年，因为你是盛家唯一的血脉。”
3. **假千金冒充真千金（14 秒）** 盛家老宅，苏婉柔拿着一份 DNA 报告，对着盛家律师哭：“我才是盛家的外孙女！”大门打开，许知衡递上真正的报告：“伪造的。真的在这里。”黑色车队停满整条街，保镖厉锋和管家艾伦带着两排人鞠躬：“恭迎大小姐回家。”
4. **物归原主（14 秒）** 陆屿把盛氏的印章和他的纹章表一起放进她手心：“我替你守了七年，现在还给你。”霍霆琛看着新闻直播，第一次笑了：“合作吗，盛小姐？”苏晚展开外婆的信，最后一行写着：“当年那场车祸不是意外。凶手，是你叫了二十二年的爸爸。”

**钩子**：终章清算。

### 第 8 章 · 全城首富（1000 亿）

1. **发布会（12 秒）** 晚星集团发布会，苏晚一身星河藏青高定礼服登台。台下坐着曾经嘲笑她的人，苏父苏母、傅景辞都在。主持人：“请问苏总，会改姓盛吗？”她：“名字是外婆起的，我不改。”
2. **公开处刑（14 秒）** 大屏幕播放外婆生前留下的录音和二十二年前的证据。全场哗然。警察走进会场，给苏父戴上手铐。苏母瘫坐在地上。
3. **白莲翻车（12 秒）** 苏婉柔躲在角落里开直播想带节奏，直播间突然被大屏幕连上，她慌乱的脸出现在全场面前。弹幕：“家人们谁懂啊，白莲当场社死。”她捂着脸逃出会场。
4. **结局（14 秒）** 旁白：“那一晚，所有人都在笑我。现在，他们排队等我回头。可我不会回头了。”**按羁绊等级最高的男主播放专属结局**（羁绊相同时默认陆屿），其他人的结局在图鉴里看广告解锁。

## 四、男主羁绊

> 每位 5 段（初遇 / 心动 / 暧昧 / 告白 / 专属约会）+ 1 段番外（看广告）+ 1 段第 8 章专属结局。每段 8~12 秒，一个场景、一两句台词。

### 陆屿 · 隐藏继承人（甜品店；Lv3/4/5 需主线第 4/6/7 章）

1. **初遇** 雨夜，他把伞撑到她推车上，自己淋着雨走回烧烤摊。她喊：“你的伞！”他头也不回：“推车比我金贵。”
2. **心动** 她烫伤了手，他一言不发地拿来冰袋按上去：“手别动。今晚我看摊。”
3. **暧昧** 打烊后两人坐在店门口分一块失败的蛋糕。他伸手擦掉她嘴角的奶油，顿了一下，收回手：“难吃。但我想天天吃。”
4. **告白** 天台，她问：“你到底是谁？”他看着她：“现在还不能说。但我是你的人，这句不会变。”（不剧透第 7 章）
5. **专属约会** 外婆老房子的屋顶，满城灯火。他把纹章表扣到她手腕上：“盛家的东西，物归原主。我也是。”
- **番外** 七年前，十七岁的他站在苏家门外的梧桐树下，远远看着她背着书包走出来，攥紧了口袋里奶奶给的照片。
- **结局** 晚星甜品店打烊，最后一块星星酥里藏着一枚戒指。他单膝跪下：“以前是我等你。这次，换我排队等你点头。”

### 江叙白 · 温柔学弟（咖啡馆）

1. **初遇** 拉花拉成一只歪歪扭扭的猫，他红着脸推过来：“送你的……姐姐。”
2. **心动** 大雨天，他骑单车绕了半座城，浑身湿透地把她落下的方子送回来：“姐姐的东西，我不会弄丢。”
3. **暧昧** 手把手教她拉花，耳朵红透。顾野路过来找她，他抬头一笑：“姐姐，他会做咖啡吗？我会。”（绿茶学弟梗）
4. **告白** 打烊后，桌上一杯拉花写着“我喜欢你”。他低着头：“我不想只做你的学弟了。”
5. **专属约会** 毕业典礼上，他把学士帽戴到她头上：“姐姐，我毕业了。现在可以正式追你了吗？”
- **番外** 他喝醉了趴在吧台上，拽着她的衣角不撒手：“姐姐别走，就五分钟。”
